
# Shopping List App

## Project Description

The Shopping List App is a simple web application that allows users to create and manage a shopping list.

## Features

- Add shopping items
- Set the quantity of each item
- Search for shopping items
- Mark items as purchased
- Edit shopping items
- Delete shopping items
- Display the total number of items

## Technologies Used

- HTML
- CSS
- JavaScript
- Git
- GitHub

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Enter a shopping item and quantity.
5. Click **Add Item** to add it to the list.

## Project Files

- `index.html` — Contains the structure of the application.
- `style.css` — Contains the styling and layout.
- `app.js` — Contains the application's functionality.

## Version Control

The project is managed using Git and GitHub. Changes are saved using meaningful commit messages to track the development process.
